# Feedback and Support

Feedback is welcome through the
[GitHub issue tracker](https://github.com/deanhume/html-minifier/issues).
The issue tracker is used for reproducible bug reports and focused enhancement
proposals; it is not a general support forum.

## Before opening an issue

1. Check the [README](README.md) and command help:

   ```powershell
   HtmlMinifier.exe --help
   ```

2. Search the [existing issues](https://github.com/deanhume/html-minifier/issues)
   to avoid duplicates.
3. Confirm the problem still occurs with the latest release.

## Report a bug

Open a new issue and include:

- The HTML Minifier version from `HtmlMinifier.exe --version`.
- Your Windows and .NET Framework versions.
- The exact command and options used, with sensitive paths or content removed.
- A minimal input file that reproduces the problem.
- The expected output and the actual output.
- Any relevant console output or error message.

Use the smallest safe example possible. Do not include passwords, access tokens,
private source code, personal information, or other secrets.

## Suggest an enhancement

Open a new issue describing:

- The problem or limitation to address.
- The proposed behavior and an example of how it would be used.
- Alternatives or workarounds you considered.
- Any compatibility impact on existing commands or minified output.

Enhancement requests should explain the use case rather than only prescribing an
implementation. Maintainers may ask for more detail before deciding whether the
change fits the project's scope.

If you intend to implement a substantial enhancement, discuss it in an issue
before opening a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md) for the
contribution process.
